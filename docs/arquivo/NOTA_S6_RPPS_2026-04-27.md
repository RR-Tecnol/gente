# S6 — RPPS/IPAM (fase 1 entregue, 2026-04-27)

## Prova de vida (S6.1)

- `routes/rpps.php`
  - novo endpoint `POST /api/v3/rpps/prova-vida/inicializar` para criar pendências da competência (idempotente).
  - `GET /api/v3/rpps/prova-vida` e `POST /api/v3/rpps/prova-vida/processar` mantidos para ciclo pendente -> bloqueio_iminente -> bloqueado.

## Scheduler

- Novo comando: `app/Console/Commands/RppsProvaVidaProcessarCommand.php`
  - `php artisan rpps:prova-vida-processar --inicializar`
- Agendamento no `Kernel`: execução mensal `04:00` com `withoutOverlapping`.

## Observações

- Inicialização usa `RPPS_BENEFICIARIO` (fallback `FUNCIONARIO` com regime RPPS).
- Não integra bloqueio de folha ainda; isso fica para continuação S6 com validação IPAM.
