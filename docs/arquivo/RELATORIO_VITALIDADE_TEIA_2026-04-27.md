## 3. Fios partidos — front `/api/v3/...` vs Laravel

Foi feita extração de strings `/api/...` no front e comparação com `route:list` (match por segmentos, com normalização). Exemplos **reais** de desalinhamento ou risco de **404 de desenho** (verificado no código):

| Problema | Front (exemplo) | Backend |
|----------|------------------|---------|
| **GET raiz inexistente** | `GET /api/v3/beneficios` em `BeneficiosView.vue` | Existem `.../beneficios/catalogo`, `.../beneficios/{funcionario_id}`, etc., **não** `GET /api/v3/beneficios` |
| **SAGRES — nomes diferentes** | `GET /api/v3/sagres/depara`, `GET /api/v3/sagres/exportacoes` em `SagresView.vue` | Rotas registadas: `preview`, `gerar`, `historico`, `download/{id}` — **não** `depara` nem `exportacoes` |
| **Tesouraria — paths do Vue vs aliases** | `TesourariaView.vue` usa `tesouraria/fluxo`, `tesouraria/movimentos`, `POST .../conta`, `POST .../movimentacao` | Em `routes/tesouraria.php` existem `contas-bancarias`, `fluxo-caixa`, aliases `tesouraria/contas` e `tesouraria/fluxo-caixa` — **não** batem com `fluxo` / `movimentos` / `conta` / `movimentacao` como no Vue |
| **Configuração API** | `GET /api/v3/configuracoes/api` em `ConfiguracaoSistemaView.vue` | Rota legada: `GET /configuracoes/api` (grupo `auth` em `web.php`, **fora** de `api/v3`) — chamada com prefixo `api/v3` provavelmente **404** |

Outros padrões extraídos (ex.: `relatorios/folha`, partes de tesouraria) continuam a merecer `rg`/`route:list` se se quiser fechar 100% dos 279 fragmentos de URL detetados no grep.

**Lista curta de “404 de desenho” comprovada:** SAGRES (`depara`, `exportacoes`); **Benefícios** (GET raiz); **Tesouraria** (vários path names); **Config. sistema** (`/api/v3/configuracoes/api`).

## 4. Ações críticas — `@click` → API → RBAC

| Área | Ação | Chamada | Rota no Laravel |
|------|------|---------|-----------------|
| Fechamento de folha | Confirmar / fechar | `api.post(\`/api/v3/folhas/${id}/confirmar\`)` | `POST api/v3/folhas/{id}/confirmar` em `folha.php` (grupo `auth` + `audit` via `api_v3`) |
| Aprovação de atestado | Aprovar / rejeitar | `api.put(\`/api/v3/atestados/${id}/${slug}\`)` com `aprovar` \| `rejeitar` | `PUT .../atestados/{id}/aprovar` e `.../rejeitar` em `atestados_v3.php` |
| Registo de ponto | Registar | `api.post('/api/v3/ponto/registro', ...)` | Definida em `api_v3_web_part1.php` / rotas ponto (Closure) |
| Transparência | Exportar | `api.post('/api/v3/transparencia/exportar', ...)` | `transparencia.php` incluída em `api_v3` — `POST` existe |

**RBAC (`hasPerfil` / `CheckPerfil`):** o router Vue aplica `meta.roles` e redireciona quem não tem perfil. No back, muitas rotas `/api/v3` estão só com `web` + `auth` + `audit`; o middleware `CheckPerfil` aparece de forma **selectiva** (ex. alguns endpoints de benefícios). As quatro ações acima estão **autenticadas**; reforço por perfil a nível de rota **não é homogéneo** em toda a API — ponto a rever em hardening, não em “fio conectado / não conectado”.

## 5. Becos sem saída (resumo)

- **Rotas Vue sem componente / sem item de menu:** coberto — estrutura consistente.  
- **Becos dinâmicos (ecrã abre, primeira chamada falha 404):** telas **SAGRES**, possivelmente **Benefícios (lista)**, **Tesouraria**, **Configuração do sistema (GET API)**.  
- **Becos “silenciosos”:** ecrãs com `try/catch` vazio ou fallback podem **não** mostrar erro (ex. `delete` em atestado com comentário `/* fallback */`).

## 6. Teste de pulso (smoke) — automático

Comando: na raiz Laravel (`gente/`):

```bash
php artisan gente:pulse-vitalidade
php artisan gente:pulse-vitalidade --http
```

- **Sem `--http`:** verifica se cada um dos **15** GETs críticos (folha, atestados, ponto, secretarias, funcionários, transparência, comunicados, notificações, organograma, abonos, banco de horas, férias, meus-holerites, PDF contra‑cheque de exemplo, e-Social pendências) **fazem match** com o router Laravel (não é 404 de roteamento).  
- **Com `--http`:** dispatch real pelo HTTP Kernel; sem cookie de sessão, **401/302/403** contam como “cabo chega ao controlador (com ou sem porteiro)”; **404/500** apontam fio partido.

Implementação: `app/Console/Commands/GentePulseVitalidadeCommand.php`.
